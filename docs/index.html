A fixed deck, a physical choice

不是每按一次键，就重新生成一个随机答案。

它更接近真实洗牌：牌序先形成，之后真正发生的是你在这副牌中的移动与选择。 倾斜不会偷偷改变牌序，确认时也不会重新抽签。

01 · SHUFFLE

一次完成整副洗牌

进入占卜时，ESP32-S3 硬件随机源通过 Fisher–Yates 生成 22 或 78 张牌的完整、不重复环形顺序。

02 · ORIENTATION

每张牌独立确定正逆位

每张牌使用独立硬件随机值确定正位或逆位。顺序与方向在第一次选择前已经固定。

03 · MOTION

倾斜只移动既有牌环

左右角度控制滚动方向与速度，五段平滑曲线保留小角度微调，也支持大角度快速浏览。

04 · CONFIRM

确认才锁定中央牌

选中的牌从环中移除，剩余牌保持原有关系。三张牌不会重复，选择时不重新读取随机源。

可验证的随机边界： 22 张模式建立牌环需要 43 个硬件随机值；78 张模式需要 155 个。 此后 IMU 只改变视野中的位置与速度。确认不是“再随机一次”，而是从既有牌环中取走中央牌。

Depth before fortune-telling

牌意不止几个关键词，也不把同一句话换标题重复。

ADV Tarot 为 22 张大牌和 56 张小牌分别整理正逆位内容。 完整模式从画面证据、牌组阶段和现实应用逐层展开；简约模式则保留适合快速查阅的核心内容。

IMG

从画面开始，而不是直接下结论

人物、方向、颜色、物件、距离与构图先被识别，再说明这些线索如何支持当前解读。

5×

五类现实领域各自成段

感情、事业、学业、财务与身心不会挤成一段，也不会用模糊吉凶替代具体观察。

逆位不是正位前加一个“不”

逆位会分别检查受阻、内化、过度、延迟、重新审视与恢复，而不是机械翻转好坏。

SRC

多来源研读，保留边界

参考 Waite 公版原典、Book T 与逐牌资料，并把星象、元素和数字作为比较坐标而非确定预言。

Made for a 240 × 135 device

microSD 是可选增强

可选资源包会启用全部 78 张正逆位透明 PNG，并将完整占卜长期归档为 JSON。 推荐 8–32GB SDHC、Class 10/U1、FAT32、MBR 单分区。

Firmware v1.1.1 · No-SD

一个文件即可通过 M5Burner 完整安装。

固件只适用于 M5Stack Cardputer ADV。下载后先核对 SHA256SUMS.txt；合并镜像已经包含 bootloader、分区表、 应用与 78 张牌面。

M5Burner · No-SD

完整合并固件

在 M5Burner 中选择这一个文件；不插 SD 也有完整 78 张牌面。

  • 文件：ADV-Tarot-Cardputer-ADV-v1.1.1-NoSD-M5Burner.bin
  • 写入地址：0x0
  • 会清除现有 NVS 设置、学习进度与占卜历史
python3 -m esptool --chip esp32s3 \ --port PORT --baud 460800 \ write_flash 0x0 \ ADV-Tarot-Cardputer-ADV-v1.1.1-NoSD-M5Burner.bin
Optional

microSD 高清增强包

不影响无卡使用；需要透明 PNG 与长期 JSON 档案时再安装。

  • 推荐：8–32GB SDHC、Class 10/U1、FAT32

microSD root └── tarot ├── cards │ ├── 00.png … 77r.png │ └── back.png └── readings
