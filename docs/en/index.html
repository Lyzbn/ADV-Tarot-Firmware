TILT TO MOVE · ENTER TO CHOOSE

A fixed deck, a physical choice

It does not generate a fresh random answer every time you press a key.

It behaves more like a physical shuffle: the deck order is established first, then you move through and choose from that deck. Tilting never secretly changes its order, and confirmation does not trigger another draw.

01 · SHUFFLE

One complete deck shuffle

On entering a reading, the ESP32-S3 hardware random source uses Fisher–Yates to create a complete, non-repeating 22- or 78-card ring.

02 · ORIENTATION

Independent upright or reversed state

Every card receives its own hardware-random orientation. Order and orientation are fixed before the first selection.

03 · MOTION

Tilt moves the existing ring

Lateral angle controls direction and speed. A smooth five-stage response keeps fine control near center and accelerates naturally.

04 · CONFIRM

Confirmation locks the centered card

The selected card leaves the ring while the remaining order stays intact. Three selections cannot repeat, and confirmation reads no new random value.

A testable randomness boundary: preparing a 22-card ring consumes 43 hardware-random values; a 78-card ring consumes 155. From there, the IMU changes only position and velocity. Confirming selects the center of the existing ring—it is not another roll of the dice.

Depth before fortune-telling

More than a few keywords—and no padding by repeating the same paragraph.

ADV Tarot provides separate upright and reversed material for all 22 Major and 56 Minor Arcana cards. Complete mode develops an interpretation from visual evidence, deck position, and practical application; concise mode keeps the essential reading close at hand.

IMG

Start with the image, not the verdict

Figures, direction, color, objects, distance, and composition are identified before explaining how they support a reading.

5×

Five practical areas stay distinct

Relationships, career, study, finances, and wellbeing each have their own section instead of collapsing into vague good or bad luck.

R↕

Reversed does not mean “upright, but no”

Reversals separately examine blockage, internalization, excess, delay, reconsideration, and recovery rather than mechanically swapping positive and negative.

SRC

Multi-source study with clear limits

Material is informed by Waite’s public-domain text, Book T, and card-specific references. Astrology, elements, and number are comparison frameworks—not guarantees of an event.

Firmware v1.0.0

Choose a first installation or a data-preserving update.

Both files target M5Stack Cardputer ADV only. Verify the download against SHA256SUMS.txt, then use the path that matches the device’s current state.

First install

Factory installation

Includes bootloader, partition table, and application for a clean install.

  • File: ADV-Tarot-Cardputer-ADV-v1.0.0-factory.bin
  • Flash offset: 0x0
  • Erases existing NVS settings, learning progress, and reading history
python3 -m esptool --chip esp32s3 \ --port PORT --baud 460800 \ write_flash 0x0 \ ADV-Tarot-Cardputer-ADV-v1.0.0-factory.bin
Existing ADV Tarot

Data-preserving update

Writes only the application partition on a device already running ADV Tarot.

  • File: ADV-Tarot-Cardputer-ADV-v1.0.0-update.bin
  • Flash offset: 0x10000
  • Normally preserves NVS settings, learning progress, and recent readings
python3 -m esptool --chip esp32s3 \ --port PORT --baud 460800 \ write_flash 0x10000 \ ADV-Tarot-Cardputer-ADV-v1.0.0-update.bin
If the device cannot be detected: switch Cardputer ADV off, hold G0, connect a USB-C data cable, then release G0 and retry. Make sure PORT is the actual device port. Never flash the Factory file at 0x10000, and never flash the Update file at 0x0.
